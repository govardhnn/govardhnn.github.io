Computer Architecture

A twelve-part series, roughly in reading order. The MIT 6.823 Computer System Architecture course (Arvind & Emer, Fall 2005) is the backbone; Hennessy & Patterson and the Sorin/Hill/Wood Primer fill in depth.

  1. History of Computing: stored program, ISA vs implementation, stack/accumulator/GPR, microprogramming, RISC, scaling walls, Iron Law, Amdahl
  2. Flynn’s Taxonomy: SISD/SIMD/MISD/MIMD, vector machines, VLIW, multithreading
  3. Floating Point Architecture: IEEE 754, rounding, guard/round/sticky, FMA, FP in the ISA
  4. Simple Instruction Pipeline: 5 stages, hazards, forwarding, stalls
  5. Branch Prediction: 2-bit counters, gshare, TAGE, BTB, return address stack
  6. Caches and Virtual Memory: tag/index/offset, 3Cs, AMAT, page tables, TLB, VIPT
  7. Multicore Cache Coherence: SWMR, MSI/MESI/MOESI, snooping, directories, false sharing
  8. Memory Model: sequential consistency, TSO, store buffers, RVWMO, atomics, DRF-SC
  9. Advanced Superscalar Architectures: wide fetch/issue, wakeup-select, SMT, reliability
  10. Out of Order Execution and Register Renaming: scoreboard, Tomasulo, rename map, ROB, LSQ
  11. Exceptions: precise exceptions, RISC-V trap CSRs, interrupts, virtual machines
  12. RISC-V ISA: formats, calling convention, extensions

Digital design foundations: Boolean Algebra, Combinational Circuits, Sequential Circuits, Synthesis, Timing and Power, RTL Design Guide.

Supplementary

Deep dives beyond the twelve-part core:

  • Main Memory and Storage: DRAM organization, memory controllers, flash and SSDs
  • Deep Learning Accelerators: rooflines, systolic arrays, TPUs, dataflows
